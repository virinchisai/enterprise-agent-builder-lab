# Synthetic IT Support Policy (practice only)

## VPN troubleshooting
Verify network connectivity. Restart the VPN client. If the problem remains, create an IT support ticket after user confirmation. Never request a password or MFA code.

## Access requests
Requests for privileged access require a manager and IT security approval. Creating a ticket does not grant access.

## Hardware replacement
Create a support request with the device type and issue. Do not promise replacement approval or shipment.
